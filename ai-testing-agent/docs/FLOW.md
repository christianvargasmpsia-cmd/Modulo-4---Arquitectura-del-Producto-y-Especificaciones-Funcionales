# Flujo paso a paso

1. Usuario describe una funcionalidad.

2. El Prompt Builder genera el prompt.

3. OpenAI crea el código Playwright.

4. El SpecWriter guarda el archivo.

5. El Runner ejecuta Playwright.

6. Se obtienen los resultados.

7. El Analyzer interpreta los errores.

8. Se clasifican los fallos.

9. Se generan recomendaciones.

10. Se crea el reporte final.
